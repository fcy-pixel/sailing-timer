# 風帆車計時系統 ⛵

以 **Streamlit** 製作的風帆車行駛計時應用程式。

## 功能

- ⏱ 精確計時器（開始 / 暫停 / 重置）
- 🏁 多圈次記錄（自動計算圈次時間與累計時間）
- 📊 即時均速計算
- ⛵ 側邊欄設定（車輛名稱、路線、距離、風速風向、備註）
- 📈 圈次時間 & 平均速度趨勢圖
- ⬇ 一鍵匯出 CSV
- 🟢 最佳圈次綠色高亮

## 使用方式

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 部署

可部署至 [Streamlit Community Cloud](https://streamlit.io/cloud)。
